# 宝塔前端打包与部署计划

日期：2026-11-18。范围：当前用户已确定的宝塔同机部署方案。

## 目标与设计

前端静态文件部署在域名根目录，真实后端直接运行于同机 8081；浏览器通过同源 `/api/` 与 `/uploads/` 访问后端。Vue History 路由由 Nginx 回退至 index.html。保留本地开发模式，生产构建不启用 Mock。只整理部署配置与文档，不更改页面和业务流程。

方案比较：沿用同域 Nginx 反代，只需在服务器配置一次；前后端独立域名需要额外 CORS、HTTPS 和图片地址处理，不符合本次已确定范围。

## 实施与验收

- [x] 显式设置 Vite 根路径，移除生产环境中仅适用于开发代理的后端地址。
- [x] 增加 `deploy/baota-locations.conf`，覆盖路由回退、API/图片代理、缓存和请求大小；README 说明宝塔现有配置的合并方式。
- [x] 执行现有单元测试、lint、生产 build；生成根层包含 index.html 的 ZIP，并核对内容。
- [x] 使用实际 Nginx 加载相同配置片段，验证直达/刷新、静态文件 404、API 路径与请求体、上传代理与图片返回。测试后端仅用隔离 HTTP 应答验证传输，不声称业务通过。
