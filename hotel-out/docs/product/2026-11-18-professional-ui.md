# 全站预订平台界面优化

## 范围与设计决策

沿用既有紫色品牌和 Vue / Element Plus 组件体系，统一游客、登录、账户、下单、商家及管理端的排版、颜色与状态。首页继续以 AI 搜索推荐为主，不恢复目的地和日期首屏。没有改动订单价格、支付、权限与登录跳转业务规则。

五阶段遵循同一份 `../../DESIGN.md`：

1. UIUX Pro Max：检索酒店预订的设计系统；第一次结果偏玻璃材质与餐饮字体，未直接采用。第二次检索 flat-design，采用清晰控件、低装饰和快速反馈原则。
2. Frontend Design：统一紫色主操作、深色正文、浅灰背景、价格色、字体、间距、圆角与响应式断点。
3. Taste：移除登录页诗句、放大衬线标题和重复营销区；保留预订所需的位置、价格、房型及照片授权信息，不套用营销站整屏模板。
4. GSAP：无需新增库；统一已有 CSS 微交互到 160ms，减少动态效果时关闭明显过渡，正文始终可见。
5. Impeccable：使用 Operate/polish 检查实际布局、焦点、窄屏和错误状态。Windows 上下文加载器长时间没有完成，已终止；采用技能允许的项目上下文读取方式继续，没有宣称其独立检测引擎通过。

## 确认问题与修复

| Bug                                      | 原因                                                                                   | 解决方式                                                                                                      |
| ---------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 页面风格割裂，品牌和操作色不一致         | 页面各自声明青绿、紫色、橙色以及不同字体，异步页面的 scoped 样式会覆盖同权重的公共规则 | 新增共享 `src/assets/platform.css` 与 DESIGN.md，页面使用语义令牌，统一标题字体；公共规则采用明确的选择器权重 |
| 登录品牌不同，装饰标题在中屏出现零散换行 | 独立登录模板使用其他名称、大号衬线诗句和满屏背景                                       | 重做登录构图，统一品牌，使用本地真实照片与简明功能说明；手机优先显示表单                                      |
| 登录格式校验提示离表单较远               | 校验只调用全局提示消息                                                                 | 表单内增加 role=alert 错误信息，输入或切换模式清除；保留现有密码显隐、角色入口、自动填充和跳转规则            |
| 搜索结果重复，筛选入口占用过多纵向空间   | 搜索表单沿用大幅宣传区；已有查询时仍同时渲染推荐卡片和结果列表                         | 桌面使用横向筛选栏，窄屏换行；有查询时显示结果列表，无查询时显示推荐；结果增加“查看房型”入口，并带上日期参数  |
| 商家工作台手机横向溢出                   | Grid 默认 min-width:auto，内部订单行有 650px 最小宽度，撑大父容器                      | 设置工作区、面板和网格子项 min-width:0，保留表格容器内部滚动；390px 与 360px 回归                             |
| 页脚在子页面提供无效的首页片段链接       | 使用当前位置的 #destinations / #featured 链接                                          | 使用实际住宿、景点、帮助和登录路由，统一精简页脚                                                              |

## 改动位置

- `src/assets/platform.css`、`src/main.js`、`DESIGN.md`：全站设计系统与样式入口。
- `src/views/client/Login/index.vue`：登录/注册布局、错误状态、品牌和图片授权。
- `src/views/client/Search/index.vue`：筛选布局、消除重复结果、房型入口。
- `src/components/common/Footer.vue`：有效导航与简洁信息。
- 现有 Vue 页面与通用组件的 scoped 样式：将重复颜色和字体声明替换为共享语义令牌，覆盖账户、下单、详情、商家和管理端。
- `scripts/professional_ui_test.py`：可重跑的界面与交互检查。
