# 首页参考图布局与详情导航修复

状态：已实现，专项浏览器回归、单元测试、静态检查及构建已执行。范围为首页视觉和酒店详情分段导航，保留现有业务功能。

## 用户需求与取舍

参照用户两张截图，首页采用浅绿首屏、居中推荐框、居中内容区域、四列住宿与景点卡片。沿用站点品牌和 AI 推荐，保留城市筛选、快捷入口、景点弹窗与住宿跳转。截图只作视觉参考，不引入航班等新业务。

详情页“滑动条”按截图中的紫色选中下划线实现：房型、评价、介绍、商家、设施、周边均支持点击定位和活动状态；自然滚动时同步选中项目。

## 确认的问题

| Bug                              | 原因                                     | 解决方式                                                             |
| -------------------------------- | ---------------------------------------- | -------------------------------------------------------------------- |
| 首页缺少参考图中的居中主次关系   | 较窄整体卡片与左对齐标题限制了构图       | 主内容最大 1400px、推荐区最大 1000px，标题居中，住宿和景点去掉外层框 |
| 详情导航只有房型带选中线         | 样式固定选择第一个按钮，没有活动段落状态 | 六项共享活动状态与定位的选中线，增加 aria-current 与对应段落关联     |
| 平滑跳转到底部时周边状态可能切走 | 最后段落无法继续滚动到吸顶导航下方       | 对文档底部单独处理，并回归普通动效、减少动态效果及手动滚动           |

复现：进入 `/hotel/1`，依次点击后五项导航；旧版下划线始终停留在房型。新版六项均显示选中线，手动滚动时同步状态，窄屏当前项自动进入导航可见范围。

## 五阶段实施

1. UIUX Pro Max：核对活动状态、吸顶遮挡、平滑滚动和窄屏规则。
2. Frontend Design：按参考图调整首页构图，保留品牌和业务入口。
3. Taste：检查等距布局、图片和价格层级，修正手机标题换行。
4. GSAP：使用 CSS 220ms 位移，无需新增动画库；遵守减少动态效果偏好，清理事件、帧和定时器。
5. Impeccable：按既有规范检查桌面、窄屏和真实交互。此前启动器不可用，使用浏览器验收代替，未宣称专用引擎通过。
