# 模型连接库与回答模式交付记录

## 实现内容

按用户选择的方案一，服务端 `AiSettingsService` 在原配置路径保存版本化连接库。读取旧单模型时兼容迁移，首次保存时原子写入新格式。连接保存名称、供应商、基础地址、模型、凭证、启用状态、温度与 Token 上限；列表不返回密钥。管理员可创建、编辑、测试、激活、删除；当前连接须先切换后删除。基础地址接受预设、自定义、完整聊天路径，保存时去除聊天后缀并规范化；修改地址不能沿用旧密钥。

界面沿用 DESIGN.md 紫色品牌，采用当前连接横幅、表格、接入弹窗。保留六种预设与自定义，宽屏双列表单、手机单列。统一管理员 AI 页面和系统配置中的 AI 入口。

首页输入区左下角支持自动、快回答、深思考。模式参数通过请求发送至服务端：快回答限制篇幅并抑制主动检索；深思考增加输出预算，在已支持的供应商上启用推理参数；自动根据长度及方案/对比/代码等特征选择模式。通用问答返回 answer；房源查询使用平台数据库，深思考允许最多三次只读检索、两轮结果反馈，最多三次模型请求。回复不展示内部思维链，价格与库存仍以房型页面为准。历史每条限制1000字符，避免长回复导致后续请求校验失败。

## 确认问题

| Bug                          | 原因                            | 解决方式                                                   |
| ---------------------------- | ------------------------------- | ---------------------------------------------------------- |
| 多模型切换覆盖已有配置       | 原服务只保存一个 Settings       | 版本化连接库、独立 ID 与当前连接指针，旧格式兼容迁移       |
| 预设地址不能修改             | 固定接口只读展示                | 弹窗允许编辑基础地址，后端统一拼接聊天端点并校验           |
| 回答模式仅靠文案无法生效     | 请求与服务端无 mode 字段        | 添加模式校验、复杂度判断、提示策略、推理参数和受限平台检索 |
| 模式菜单套用绿色发送按钮样式 | 首页 CSS 对所有后代 button 生效 | 将发送按钮选择器改为直接子元素                             |
| 长回复导致下一轮请求失败     | 历史内容最大1000字符            | 提交前截断历史，完整当前回复仍展示                         |
| 旧配置缺少新增预算字段       | 老 JSON 没有 maxTokens          | 旧格式读取时使用默认预算构造器                             |

## 生效与边界

需要重启后端并刷新前端；生产环境需重新部署构建文件。MySQL无需变更。现有真实密钥和配置未通过测试脚本改写。连接库沿用服务端本地文件存储，文件权限与服务器备份由部署环境管理；未新增静态加密。推理参数只对现有明确适配的供应商发送，自定义兼容网关依赖其自身模型能力。自动判断为规则路由，不额外调用收费模型。工具范围为平台房源检索，无互联网浏览和代码执行；不包括截图中菜单语义检索、Embedding或对话审计模块。
