# 城市景点与酒店数据扩展

## 交付内容

为 Mock 与数据库初始化数据补充南京、重庆、西安、青岛、三亚、武汉、苏州、桂林八座城市。每座城市新增 2 个酒店/民宿、3 个景点和区域筛选项；新酒店包含图片、房型、库存、价格、设施与详情页所需字段。首页推荐、搜索筛选、详情页、AI 找房和订单演示均复用同一份酒店数据结构。

数据库脚本同步新增 16 个酒店和对应房型，统一挂在初始化商家下，导入后可通过真实 API 搜索；景点保持前端静态目录，因为现有数据库没有景点表。

## 验证

- 前端数据检查：64 条 Mock 酒店、74 条景点、16 个可选城市，新增城市每城至少 2 条酒店、3 条景点和 3 个区域。
- 新增目录测试校验房型、图片和城市筛选字段。
- ESLint 通过，31 项既有单元测试与 2 项目录测试通过，生产构建通过。
- SQL 只做结构化脚本检查，实际导入 MySQL 需在目标数据库执行后再验收。

## 数据说明

新增图片使用现有项目的远程图片策略，景点素材为展示用图片链接，最终上线前应根据实际版权和运营资料替换；地址、价格、评分和库存属于演示数据，实际预订以数据库房态为准。
